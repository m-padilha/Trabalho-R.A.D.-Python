Este trabalho simula um Sistema de Gestão Acadêmica usando Python e SQLite

Use o menu para: <br>
1 — Cadastrar aluno <br>
2 — Listar alunos <br>
3 — Atualizar aluno (informe o ID) <br>
4 — Excluir aluno (informe o ID) <br>
5 — Sair do Programa <br>

Ao atualizar as informações de um Aluno, você pode digitar '0' para poder manter as informações do campo atual caso deseje manter algumas informações do aluno.
